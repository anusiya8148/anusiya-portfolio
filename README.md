# Anusiya R — Portfolio

A modern, responsive personal portfolio showcasing full-stack web development projects, technical skills, academic background, internships, hackathon achievements, certifications, and contact integration.

## Tech Stack
- React
- Vite
- JavaScript/TypeScript
- Tailwind CSS
- EmailJS

## Features
- Responsive portfolio (Desktop & Mobile optimized)
- Projects showcase with live links and source code
- Technical & Professional Skills
- Education details
- Work & Internship Experience
- Certifications
- Hackathons & Awards
- Verified Resume PDF view & download
- Interactive Contact Form with EmailJS integration

## Run Locally

```bash
npm install
npm run dev
```
